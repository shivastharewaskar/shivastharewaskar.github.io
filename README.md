## 🎨 Sections & Design Breakdown

1. **Header & Navigation:**
   - Fixed top position with dark glassmorphism blur (`backdrop-filter: blur(14px)`).
   - Monospace brand logo: `> sr_portfolio`.
   - Desktop anchor links (`Projects`, `Certifications`, `About & Contact`) + mobile animated hamburger toggle and slide-down drawer.
2. **Hero Section (Centered, Above the Fold):**
   - High-contrast pure crisp white heading for `Shivastha Rewaskar`.
   - Distinctive headline: `Aspiring Data Analyst | Business Analyst | Computer Science Engineer`.
   - Focused value proposition summary.
   - Quick skills strip (`Python`, `SQL`, `Power BI`, `Excel`, `DAX`, `Pandas`, etc.).
   - CTA actions: "Contact Me" and "View Projects".
3. **Projects Grid (Recruiter-Ready Cards):**
   - **Card 1 (Sunflower Yellow `#ffdd00`):** Customer Churn and Retention Analysis Dashboard (Power BI, Excel, DAX, Power Query)
   - **Card 2 (Magenta `#ec4899`):** Sales Performance and Business Insights Analysis (Python, SQL, Excel, Power BI, Pandas)
   - **Card 3 (Golden Amber `#f59e0b`):** Sentiment and Emotion Analysis Framework for Hate Speech Detection (Python, NLTK, PyTorch, BERT, NLP)
4. **Certifications & Professional Development:**
   - 3-column milestone grid:
     - **Business Intelligence (Sage Green):** Power BI & Data Analytics
     - **Database & SQL (Cyan):** SQL & Relational Databases
     - **Analytics & Python (Soft Rose):** Python for Data Analysis & Visualization
   - Direct verification link to LinkedIn profile.
5. **Unified Contact & Academic Panel:**
   - Left side: Full "About" statement.
   - Right side: Stack of academic background boxes (BE Computer Science, CGPA 8.84/10, plus Higher Secondary education).
   - Horizontal separator rule.
   - Bottom row: Direct mailto email with copy button, LinkedIn link, and GitHub profile link.
6. **Minimal Terminal Footer:**
   - Status indicator: "Available for Data & Business Analyst Roles".
   - Social links and back to top smooth scrolling link.

## 🌐 Deploying to GitHub Pages

1. Target repository: `https://github.com/shivastharewaskar/shivastharewaskar.github.io`
2. Pushed directly to the `main` branch.
3. In GitHub: go to **Settings** > **Pages** > select **Deploy from a branch** > branch `main` (`/root`).
4. Your portfolio is published at `https://shivastharewaskar.github.io/`!
